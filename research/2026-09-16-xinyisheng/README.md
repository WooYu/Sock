# 股票笔记重解析与新易盛三年历史检验

本次任务：从 WooYu/ObsidianNote 的 `印象笔记/股票` 获取最新 Markdown，由当前 Codex AI 重新进行语义解析，保留原文行号；使用新易盛 300502 的真实日 K 线检验可计算规则及未来 1–4 个交易日的价格、MA、BOLL 预测。当前目录是研究产物，不自动发布为生产交易规则。

## 固定来源与边界

- 笔记仓库提交：`707f4fe0032ff44f309e7f374ba68f16d9e065af`，140 个 Markdown 文件。
- 行情：腾讯按年分段获取的日线，新浪未复权日线交叉检查。原始响应、时间戳、URL 和 SHA256 保留在 `sources/` 和 `source-manifest.json`。
- 评估范围：2023-09-18 至 2026-09-16，以返回的有效交易日为准。额外历史只供指标预热。
- AI 解析方式：当前会话的模型逐篇语义阅读，输出 `extraction-batch-*.json`，不是旧关键词提取器，也不额外调用外部 AI API。
- 所有数值预测只能读取预测原点及之前数据；历史类比只能使用后续 4 日已经在预测原点前结束的样本。时间留出区间不参与选择参数。
- 当前仓库的笔记版本晚于部分回测日期；因此这是今天整理规则后的历史回溯检验，不等于当年的真实实时样本外业绩。
- 股票由用户指定，单只股票不能证明规则对所有 A 股有效；前复权使用本次数据版本，须披露其并非历史逐日保存的复权版本。
- 没有完整日线定义的术语不会被声称已经精确验证；代理定义、所需外部数据、分时数据和图像缺失会分别记录。

实际前复权日线最后为2026-09-15，因此最终评估为2023-09-18至2026-09-15，共725个交易日。9月16日仅原始行情可见，没有人为拼接。

## 离线重跑

在本目录使用Python 3.12及`requirements.txt`。当前已在项目的忽略目录`.research-sources/analysis-venv`建立隔离环境，未修改系统Python包。

```powershell
python -m pip install -r requirements.txt
python -m unittest test_backtest.py
python validate_inputs.py
python backtest.py
python evaluate_principles.py
python render_report.py
python make_notebook.py
```

上述流程使用保存的真实来源，不重新访问行情服务。`make_notebook.py`会实际执行全部单元，重算回测和图表。

只有需要一个新的行情版本时，才运行`python fetch_sources.py --refresh`；该操作会改变本目录固定数据，正式研究应先复制为新研究批次并登记新的方法版本。`build_catalog.py`用于重新校验AI引文和生成前端只读资料包，需保留`.research-sources/ObsidianNote`的固定提交检出。
