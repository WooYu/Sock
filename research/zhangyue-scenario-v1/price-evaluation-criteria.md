# 价格参考位的验证标准（2026-10-16）

用户指定的主要标准：计算价与实际当日开盘、最高、最低、收盘价接近，偏差小于1%可认为较好，价格一致最好；或者接近当日盘中反复遇阻、获得支撑的关键价位。后续评估以这两类结果为主，保留逐项明细。

## 1. 与当日开高低收比较

对每一个实际展示的计算价 P，分别与实际开盘、最高、最低、收盘价 A 比较：

`相对偏差 = abs(P - A) / A`

- 严格小于0.01记为“接近”；恰好等于1%不计入，使用未格式化的误差判断。
- 预测价和实际价按股票最小报价单位0.01元一致，单独记为“价格一致”。
- 每个预测价保留四项误差、最近的实际价及全部符合项；任一项接近，即通过“四价接近”这一标准。
- 反向逐项检查开、高、低、收分别是否被任一计算价覆盖，明确列出没有覆盖的项目。
- 一个预测价可以同时接近最低价和收盘价；预测价通过比例与四价覆盖比例使用不同分母，不能混称为策略胜率。
- 所有实际计算并按既定涨跌幅筛选的价位均进入评估，包括未接近的价位；不根据结果补价、删价或改选方法。保留候选数量，以便识别单纯增加价位造成的覆盖提升。

没有预先声明某个价位用于预测最高价时，不因事后最近匹配就给它增加“最高价预测”的角色。明确指定过角色的预测还须单独报告对应目标的误差。

## 2. 与盘中关键价位比较

该路径可以与“四价接近”并列成立，尤其用于四价之间的支撑、压力区域：

- 记录接近价位的独立次数、接近方向、停留时长和离开后的价格反应。
- 从下方接近后回落，是压力候选证据；从上方接近后反弹，是支撑候选证据；突破后的回踩、跌破后的反抽另记角色变化。
- 连续多根K线停留在同一区域，只记一次连续访问；离开后再次返回才是新的访问。
- 某价位落在日K的最高最低之间，只能表述为日线范围包含它，不能证明频繁触及或形成支撑、压力。
- 需要分钟或分时序列；采样频率限制结论精度。只有分钟OHLC时，不还原同一根柱内的先后顺序，也不把每分钟采样次数等同逐笔成交密集度。
- “反复”需要几次、离开多远、反弹或回落多大以及观察时长尚未由样本校准。本阶段保留原始证据并人工核对；缺乏数据或条件定义时标记“待核对”，不自动确认。

若有明确的支撑或压力价位 A，预测价与其接近程度同样使用 `abs(P - A) / A < 0.01`；必须同时保留支撑、压力本身的证据，不能只凭价格接近就确认其性质。

## 3. 时点和已有规则

- 收盘后生成的价格用于后续窗口；不得对照生成前已经发生的当日开盘、最高或最低来主张提前预测成功。盘中计划只核对生成之后且有足够细粒度数据的窗口。
- 回放只使用原点当时已知的K线计算，保留实际创建时间，并标为事后研究；不能冒充交易开始前已经保存的计划。
- 未来第1、2、3根MA/BOLL参考位可以用于预先选定的当前执行窗口，不把各周期的第几根混成相同的未来日期。
- 现有“相近预测价按1%合并取平均”是另一条规则；此处的1%比较的是预测价与实际价，分别记录。
- 继续采用日线优先、必要时逐级核对、规律明确后最多补一个下级周期的约束，不为评估强制增加预测周期。
- MA/BOLL自身预测误差、参考价范围覆盖和交易盈亏继续分开；本标准不把价格接近直接当作盈利。

## 4. 已核算的示例

使用已有14日收盘、只含日线的回放结果，对比15日完整日K；没有使用15日行情重新选择这五个参考价。原点收盘29.92元，实际15日开29.51、高32.91、低28.95、收29.01。

| 计算价 | 最近的实际四价 | 实际价 | 偏差 | 小于1% |
| ---: | --- | ---: | ---: | --- |
| 30.75 | 开盘 | 29.51 | 4.20% | 否 |
| 29.75 | 开盘 | 29.51 | 0.81% | 是 |
| 29.04 | 收盘 | 29.01 | 0.10% | 是 |
| 28.65 | 最低 | 28.95 | 1.04% | 否 |
| 27.69 | 最低 | 28.95 | 4.35% | 否 |

5个计算价中2个符合四价接近标准；四价反向核对有3个被覆盖：开盘0.81%、最低0.31%、收盘0.10%；最高价最近的预测值30.75，误差6.56%，未覆盖。没有价格完全一致的项目。同一个29.04同时接近最低与收盘，这两种统计不可互换。

这是单个事后算例，停止周期的人工确认也是事后假设，不能由40%或75%的算例比例推断整体准确率或策略胜率。未选择15日盘中路径，支撑、压力标准标为“未评估”。

## 5. 根据测试结果持续总结规律

用户进一步要求：利用AI从测试结果持续学习、总结新的计算规律。学习结果保存为可追溯的候选规则和样本记录，供后续验证与版本比较，而不只保存一段总结文字。

流程为：冻结计算及来源→对照实际行情评分→按当时已知的趋势等条件归纳成功和失败案例→提出有公式与适用条件的候选→固定候选后，用新的时间窗口验证→保留通过与未通过的证据及版本。

AI不得只挑成功案例或按后续行情补价。总结使用过的样本不能继续冒充未见验证资料；自动方向候选、经确认的趋势和葛阶段分别记录。后续规则变化应保留旧版、失效条件和回退依据；新版本是否有额外价值需要与原算法和简单基准比较。盘中支撑、压力没有数据时继续标记未评估。
