# 笔记条件价格模型 v1

日期：2026-10-25。定位为影子研究，尚未证明预测增益。保留原文哈希、逐字引文、失效条件和程序定义；不修改源研究的 `untested` 状态或人工版本。

## 已实现

- MA5 条件临界价：最近四个完整收盘的均值，是明日收盘不低于明日 MA5 的代数边界，不是收盘预测。
- 攀升高点：MA5 向上，连续 N 根收盘距各自 BOLL20/2 上轨不超过阈值。以两根间上轨平均增量外推，价格目标为下一根最高价；默认对应第 2 根上轨，允许另存第 1 根映射。形态阈值和映射均为研究定义。
- 反抽高点：收盘低于 MA5 且 MA5 向下，以 MA5 一根增量外推作为下一根最高价的实验代理。原文只说动态五日线，未承诺该固定数值或最高价映射。
- 学习页 271 条主张都有规则卡状态，未绑定模型的主张保留缺口；自动预估的原有 12 条条件规则用于过滤和风险判断，不代表标签直接改变价格公式。

## 使用与留存

主页面“笔记驱动价位 · 影子研究”可查看计算、原文、输入和失效条件，在“研究定义与人工调整”另存参数版本。“冻结本次笔记计算”保存输入、目标、参数与结果；刷新行情后选择记录核对，再用“冻结本次核对结果”追加评分版本，保存当时实际行情与成功／失败结果。参数修改和后续行情不会覆写旧记录。

记录仅保存在当前浏览器，导出包含预测与已冻结核对历史。存储损坏会禁写并提供原始备份，不静默清空。历史回放、合成示例、日期未核实与本地盘前记录分别标记；本地时钟不构成服务器事前凭证。没有核实交易日历时保留第几根目标，不用自然日补造日期。

## 历史对照协议

在 `frontend` 运行 `npm run notes:forecast:audit`，直接编译应用计算模块，离线读取已有冻结数据，生成 [完整结果](historical-audit.json)。不联网、不重新提取笔记。报告包含数据文件哈希、采集时间、价格口径、每个原点的输出／未输出原因和实际最高价。

两份数据分别为 603533 不复权 640 根完整日线，以及 300502 前复权 1140 根日线。按时间前 80% 研究、后 20% 留出；每个原点最多传入此前 60 根完整日线，目标日期在计算后才按后续观察序列解析。历史交易日历未经逐日核实。最高价预测只对最高价评分，严格误差小于 1% 才算命中；另列同原点前高、前收与无条件外推，以及无条件全部原点覆盖结果。MA5 临界价不计作收盘预测命中。

研究段至少 30 个模型样本才估计残差中位数和 10%～90% 区间，冻结用于留出段。修正只是离线候选，没有启用到应用默认值。

这些都是已看过的历史，时间留出不等于新的未见样本或前瞻验证；前复权使用采集时统一版本。没有分钟路径，不能证明压力反应或交易胜率。后续需保留真实未来窗口的影子记录，并扩展独立股票与行情阶段，再考虑是否调整模型地位。
