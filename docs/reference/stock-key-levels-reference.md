# 参考站「位界 KEYLINE」结构分析

> 来源：https://stock-key-levels.amos369.chatgpt.site/（演示模式，无需登录）。用于对齐 StockCal 的交互与结构。

## 主题（2 套）

- **浅色**：白 `#FFFFFF` + 浅灰 `#F5F6F8` 背景。
- **深色**：深海军蓝 `#0B1220` + 薄荷青 `#47D7C7` 主色（用户截图提供）。

## 布局

- **左侧导航栏**（桌面）+ 顶部搜索框（`⌘K` 命令面板）+ 通知 + 头像。
- 顶部横幅「演示数据 · 不构成投资建议」。

## 导航（约 10 项）

关键位分析 / 盈利模式 / 未来指标 / 预测记录 / 交易与盈亏 / 统计图表 / 当日复盘 / AI策略 / 经验规则

## 核心页面「关键位分析」（长滚动页，包含多区块）

1. **个股头部**：名称/代码/行业/自选标签 + 现价 + 涨跌 + 操作周期（短线/波段/中长线）。
2. **方向强度**：64/100 仪表，空头/中性/多头。
3. **盈利模式识别 · 规则匹配**：
   - 今日参数 / 振幅匹配 / 规则命中（8/11）
   - 策略列表按分数排序：主策略(86 攀升)、备选(74 照镜子止盈)、风控(61 反弹止损)、警戒(39 弱势处理)
4. **主策略详情**：买入关注区间、卖出/止盈区间、失效条件 + 条件勾选（MA5 上移、BOLL 抬升、振幅）。
5. **历史数据校准 · 公司行为**：除权除息（分红/拆分）自动纳入指标计算 + 复权参考价。
6. **模型编排 · 可解释分析（AI策略分析中心）**：三层流水线可视化——
   - 数值计算层（MA·BOLL·ATR·振幅，12 项参数）→ 规则引擎层（个人经验·策略条件，8/11 命中）→ AI 解释层（复杂推理，86 分）
   - 策略结论 / 解释依据 / 待确认经验
   - 策略匹配度 86 / 规则可信度 78 / 风险等级 中等
   - 当前模型：GPT-5 轻量分类模型

## 组合总览（首页）

- 组合总览卡：持仓股票 N 只 / 总投入 / 当前市值 / 总浮动盈亏 / 已实现盈亏 / 组合收益率。
- 持仓表格：`股票 | 持仓/成本 | 现价/市值 | 浮动盈亏 | 收益率`，每行「查看详情 →」。

## 对 StockCal 的映射

| 参考站 | StockCal 现状 | 差距 |
|---|---|---|
| 关键位分析（方向强度+盈利模式识别+主策略详情+AI流水线） | 个股分析（支撑/压力/目标+命中规则） | 缺方向强度仪表、策略排序、AI流水线可视化 |
| 组合总览（持仓表） | 组合 tab | 较接近 |
| 经验规则 | 知识规则（笔记→规则） | 缺规则管理（正在做） |
| 2 套主题（浅/深） | 已有浅色/深色 | 已满足 |
| 左导航 + ⌘K 搜索 | 4 tab 底部导航 | 结构不同 |
