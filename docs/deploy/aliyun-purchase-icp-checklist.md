# 阿里云购买 + ICP 备案逐屏操作清单

> 配合 `aliyun-production-runbook.md` 使用。本清单把"买服务器"和"ICP 备案"两个最耗时、最容易被界面绕晕的环节拆成逐屏步骤。
> 阿里云控制台界面会不定期改版，**按钮名称和位置以你实际看到的为准**，本清单给出的是稳定不变的流程主线。

---

## 第一部分：购买阿里云轻量应用服务器

### 0. 前置准备

- 一个阿里云账号（手机号即可注册）。
- **完成实名认证**：个人上传身份证，企业上传营业执照。不实名无法买境内服务器、也无法备案。

### 1. 进入购买页

1. 打开 https://www.aliyun.com 并登录。
2. 顶部「产品」→ 计算类目 → 找到「**轻量应用服务器**」（Simple Application Server，个人用比 ECS 便宜省心）。
3. 点「立即购买」。

### 2. 关键配置（逐项照抄，其余默认）

| 配置项 | 选择 | 说明 |
|---|---|---|
| 地域 | **大陆**节点（华东 1/华北 2/华南 1 等） | 必须大陆才能备案；离你近更快 |
| 镜像 | 系统镜像 → **Ubuntu 22.04 或 24.04** | 后面装 Docker 用 |
| 套餐 | **2 核 2G** 起步 | Spring Boot + Postgres + Redis 个人够用 |
| 购买时长 | 先买 1 个月试跑，顺手可买 1 年 | 备案要求服务器不能太早释放 |
| 其他 | 默认 | 数据盘、带宽按默认 |

### 3. 下单 + 购买后必做

1. 确认订单 → 支付。
2. 回到「轻量应用服务器」控制台，**记下公网 IP**（形如 `47.xx.xx.xx`）。
3. **重置 root 密码**：实例卡片 → 「重置密码」，设一个强密码，重启实例生效。
4. **放行端口**：实例 → 「防火墙」→ 添加规则，放行：

| 端口 | 用途 | 阶段 |
|---|---|---|
| 22 | SSH 登录 | 立即 |
| 8080 | 后端 API | 立即（备案前手机连 `http://IP:8080`） |
| 80 / 443 | HTTP / HTTPS | 备案通过后 |

> 之后回到 `aliyun-production-runbook.md` 的 A3–A6，装 Docker、拉代码、填 `.env`、启动。

## 第二部分：ICP 备案（逐屏）

### 前提清单（缺一不可）

- 域名已完成**实名认证**。
- 有一台**大陆**服务器（就是上面买的那台）。
- 主体证件（个人：身份证；企业：营业执照 + 法人信息）。

### 备案流程（约 10 步，1–4 周）

1. 打开阿里云备案系统 https://beian.aliyun.com（或从「备案」入口进入）。
2. 点「**开始备案**」/「新增备案」，选择「首次备案」。
3. **填写主体信息**：个人填姓名、身份证号、手机号、联系地址；企业另需营业执照号、法人信息。
4. **填写网站信息**：
   - 网站名称：不能是"股票""证券"等敏感词，可用「个人学习记录」之类中性名称；
   - 域名：填你的域名；
   - 服务器：选「阿里云」，关联你买的那台实例；
   - 网站负责人：本人。
5. **上传证件**：身份证正反面照片、手持身份证照（部分要求）。
6. **人脸核验 / 短信核验**：按提示完成活体检测或短信验证。
7. 提交后 **阿里云初审**（约 1–2 个工作日，有驳回会短信通知，按提示改）。
8. 初审通过后提交到**管局审核**。
9. 管局审核期间可能来电/短信**核验**（务必接听，回答与备案信息一致）。
10. 通过后你会收到**备案号**（如「浙ICP备XXXXXXXX号」）。把它放到网站页脚，并完成**公安备案**（备案通过后 30 天内，按阿里云提示操作）。

### 备案期间怎么办

- 备案通过前，域名 80/443 端口不能对外提供 Web 服务。
- **手机先用 `http://<公网IP>:8080` 访问**，功能完全正常，只是地址是 IP。
- 备案通过后再做 DNS 解析 + HTTPS（见 `aliyun-production-runbook.md` 的 C 线）。

## 第三部分：Tushare 行情 token（可选）

### 1. 获取 token

1. 打开 https://tushare.pro ，点「注册」（手机号或邮箱）。
2. 登录后进入「**个人主页**」/「个人中心」。
3. 找到「**接口 TOKEN**」，点复制（形如 `xxxxxxxxxxxxxxxx`）。
4. 留意你的**积分等级**：新账号积分较低，日线等基础接口可用；更高权限（分钟线、部分专题接口）需签到/做任务/充值攒积分。先用基础日线跑通即可。

### 2. 填入 .env

在服务器（或本地）的 StockCal 项目目录：

```bash
cd stockcal
vi .env        # Docker 部署；本地开发则改 .env.local
```

找到这一行，填上 token：

```dotenv
TUSHARE_TOKEN=你的token
```

> 没配置 token 时行情接口按设计返回"不可用"，其余本地功能与 AI 分析不受影响。

### 3. 重启生效

```bash
docker compose up -d
```

用 App 进入「个股分析」搜索一只 A 股，能拉到真实行情即说明 token 生效。
