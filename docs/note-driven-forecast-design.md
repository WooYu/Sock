# 让笔记参与价格计算与 K 线预估的设计建议

日期：2026-10-24；实施更新：2026-10-25。本文保留原设计，首批规则卡、三种计算入口、冻结预测、追加核对版本与离线历史对照已实现。模型尚未证明预测增益，不自动进入默认预测算法；验证协议、结果和操作说明见 [实施记录](../research/note-price-models-v1/README.md)。其余规划不代表已经实现。

## 判断

笔记能参与价格计算，也能提供 K 线预测假设；能否提升预测效果需要逐条验证。之前审计的“标签对数值作用为 0”，说明当时的软件没有消费这些标签，不能据此判定笔记没有预测价值。

更关键的区别是：已知历史数据可以确定一个指标值、阈值或估值；它们通常不能唯一确定未来股价。笔记中“何种形态看哪一条线、看哪一天、用作高点还是低点”才是连接指标计算和价格预测的关键，需要保留而不是压缩成 MA/BOLL 两个主题标签。

## 当前资料能支持什么

本次读取 `frontend/src/server/note-study-seed.json`，146 篇笔记共 271 条 AI 候选主张：

| 候选可计算性 | 数量 | 含义 |
| --- | ---: | --- |
| direct | 6 | 有可直接表述的算式或关系，仍可能有数据口径或执行定义缺口 |
| needs_definition | 227 | 缺少阈值、时点、模式定义、目标映射等 |
| needs_data | 1 | 缺数据支持的历史参考 |
| reference | 37 | 背景、案例及解释性主张 |

所有 271 条的研究状态目前都是 `untested`。6 条 direct 分别涉及成本价 7% 止损、单股 20% 仓位、MA5 平均值、EPS×PE 估值算例、双高高低点关系、滚动 PE；不能将它们称为 6 个经过验证的股价预测模型。

原文《20250910-锂电池按照计划进行（前三天后三天算参数）》提供了具体研究入口。本次已对以下引用与完整原文的行号、逐字内容核验：

- L16：“五日线就是五天的收盘价的平均值。”——指标定义。
- L16：“一个是差一点八五，一个是差一点七六……加上35块六毛八，等于37块四毛八啊”——指标增量外推的案例。
- L14：“在布林线上轨啊，贴着布林线上轨反复的去新高”“他每天的高点都是明天的布林线上轨”——形态到高点目标的假设。
- L16：“照镜子图算哪天，算后天”——目标时间选择的线索，但同段案例与其他明日参数叙述尚需厘清，不能自行固定所有照镜子模型为两天。

## 分开四种任务

| 任务 | 笔记的贡献 | 应输出什么 |
| --- | --- | --- |
| 确定性计算 | 指标公式、仓位、止损、阈值 | 算式、输入、数值和口径 |
| 条件价格计算 | 某种状态成立所需的价格、给定价格路径下的未来指标 | 临界价格或条件参考，写清假设 |
| 概率预测 | 哪种形态下，哪个未来时点的最高／最低／收盘更接近某条线 | 明确目标的预测价／区间、样本及误差 |
| 交易决策 | 是否参与、持有、退出及风险预算 | 决策约束；与价格预测评分分开 |

例如，设最近四个完整收盘为 10.0、10.2、10.4、10.6，明日收盘为未知的 x：

`MA5_明日 = (41.2 + x) / 5`

“明日收盘不低于明日 MA5”的条件可解为：

`x >= (41.2 + x)/5  ⇔  x >= 10.30`

因此 10.30 是可以精确计算的临界价格；这个代数推导来自 MA5 定义，不是笔记原文另给的预测公式，也没有推断明天一定收在 10.30。若要预测明日收盘，还需要条件统计模型。

## 核心链路

```mermaid
flowchart LR
  A[原文与逐字引用] --> B[拆成独立研究主张]
  B --> C[冻结规则定义与缺项]
  C --> D[用当时可知行情识别适用条件]
  D --> E[选择目标角色、周期和预测窗口]
  E --> F[计算指标或条件价格模型]
  F --> G[保存事前预测与失效条件]
  G --> H[对后续真实行情评分]
  H --> I[保留有效模型或记录失败]
```

标签负责检索和分类；独立规则卡负责执行。规则卡至少需要：

- 原文引用、文件哈希、规则版本，区分原文、人工补定义、由数据估计的参数。
- 输入指标、周期、复权口径、数据完整性及截至时点。
- 可执行的形态条件：例如“贴上轨”的距离和连续柱数。原文没定义时列为缺项；人工先统一标注或用研究样本确定候选参数，不把参数冒充作者原话。
- 预测对象：某一窗口的高、低、收盘、支撑、压力或指标值；明确目标第几根、所属周期，不能混用。
- 计算方法和未来未知输入的处理；如平均增量外推、平价路径、概率路径，必须分别留版本。
- 失效条件与冲突处理；条件不足可以不出预测，不能为了展示一根完整蜡烛补造数值。
- 研究／验证／启用状态及评估结果。“可计算”与“有预测增益”分别记录。

例如，“攀升看明日上轨”应编成一张规则卡：先确认日线攀升及贴上轨条件，再明确最高价所在日和指标目标日。原文“每天的高点都是明天的布林线上轨”涉及跨日映射：若按字面将执行窗口 T+1 的高点映射到其“明天”，指标目标日是 T+2，不能未经确认就改成 T+1 上轨预测 T+1 高点。应结合案例核对原点与目标日；未厘清时保留独立候选解释。所有指标估计只能使用原点 T 当时已知的信息，之后按声明的高点窗口评分。

## 怎样让笔记真正改变价格输出

不能只把所有指标预测价合并，再附上相关笔记。应先由规则选择目标和指标：

1. 根据当时已知的行情匹配笔记条件，判断适用还是条件不足。
2. 每条适用规则声明预测哪个价、在哪个窗口，并分别保存价格目标日和指标目标日。例如攀升高点模型需先确定跨日映射；反抽模型观察日 MA5 压力，不把压力直接称为下一日收盘预测。
3. 用冻结的算法计算初始价；未来 BOLL 依赖未来收盘时，使用明确的外推或价格情景，不能代入预测之后才知道的真实收盘。
4. 有足够训练数据时，可估计“真实高点相对预测上轨”的残差分布，得到偏差修正和预测区间；修正量来自历史样本，不能凭标签数量或 AI 语气加权。
5. 只合并同一目标角色、同一预测窗口、同一价格口径的结果。不同角色作为独立候选；冲突与不适用分支保留。
6. 保存预测时的条件、价位、算法、原文版本和未采用原因，供之后对照。

这样笔记能决定计算哪条线、预测哪个价格、选哪个时间、排除什么模型，以及在有证据时修正多少。它对数值的贡献就能通过删除该规则的实验衡量。

## K 线预估如何展示

现有笔记更适合先预测关键位、突破／回踩事件和高低点区间。完整 K 线至少需要开、高、低、收四个相互关联的量；“高点参考明日上轨”没有提供开盘、最低和收盘的完整生成关系。

第一阶段输出主情景／备选情景、目标区间和失效价。没有校准过的数据时不显示百分比概率，也不把情景曲线当作已证实的未来路径。

若以后做完整蜡烛预估，需另建开盘跳空、日内波动和收盘的联合模型，并满足 `L <= min(O,C) <= max(O,C) <= H`、价格为正、对应市场交易约束。可从经过验证的条件分布中产生多条可能路径及区间；不能将四个独立指标值直接拼成一根确定蜡烛。只有日 OHLC 时也不能声称知道日内先高后低的顺序。

## 如何证明笔记有增益

使用同一股票池、同一预测窗口、同一目标角色和相同候选价数量预算比较：简单基准、现有指标外推、加笔记条件、再加样本估计修正。删除单条规则分别看变化；合并模型的增益不能自动归因给每条笔记。

按时间先研究、再选择参数、最后冻结到未参与开发的验证窗口，必要时在切分边界剔除跨越未来目标的重叠样本。股票、趋势、波动状态分组报告；失败、空预测和覆盖率都保留。使用当前点以前可得的数据和一致的复权基准，不能用事后更新的指标或全段最优参数重算过去。

主要评分应与声明的目标一致：

- 最高价模型比较真实最高价，最低价模型比较真实最低价；报告相对误差和用户约定的严格小于 1% 接近比例。
- “任意接近开高低收”保留为已有参考价标准，不能替代指定目标评分；同时报告候选数，避免多报价格提高覆盖。
- 区间报告覆盖率与宽度，避免靠无限放宽区间取得好结果。
- 支撑／压力另需分钟访问与反应证据；日线范围包含某价不等于验证了支撑。
- 有概率输出后再检验概率校准；交易盈亏另计费用、滑点与执行限制。

仓库既有 `research/zhangyue-scenario-v1/learning-2026-10-16/README.md` 已记录一次 40 个研究、20 个时序验证样本的试验。“按方向选择算法”没有超过更强固定方法及单点基准的研究分数，且部分验证样本此前已见。因此该候选保持不启用；不能把这 60 个案例继续当成新模型的严格未见测试集。

## 推荐实施顺序与验收

1. 复用现有 271 条研究主张，补齐规则卡和状态，不再只扩充资料标签。先选 MA5 条件阈值、攀升上轨高点、下跌反抽 MA5 压力三个可分别验证的研究入口；模糊定义与跨日映射保留人工标注通道。
2. 为每个模型明确单一目标、时点和计算方法，并把“规则选择前”和“选择后”的价位分别保存。验收应能从一条输出价回溯到原文、具体公式、输入、适用条件与失效条件。
3. 离线做时序及跨股票对照，再做事前保存的影子运行。验收要能说明相对相同目标的基准，误差、覆盖、区间宽度和输出频率如何变化；不能只给成功截图。
4. 有增益的模型才进入默认价位与情景展示，无增益的保留为解释／风险知识，继续记录失败原因。完整 K 线联合预测作为后续独立阶段，不能用标签接入代替。

当前项目已具备原文证据、逐篇主张、情景计算、规则核对和部分评估基础；缺的重点是“形态到目标价格／时间”的完整可执行映射，以及这个映射的独立验证。上一轮预估作用分类提供了入口，尚未完成这里提出的条件价格模型。
