# K 线研究工作台实施计划

**Goal:** 将首页重做为可以选股、看图绘图、查看三日预测和证据的研究工作台。
**Architecture:** 新增 research 页面组合组件，复用 StockWorkspaceProvider 与 ChartWorkspace，保留现有后台和持久化协议。
**Tech Stack:** Next.js 16.3.3、React 19、TypeScript、SVG、Vitest、Playwright。
**Spec:** ../specs/2026-09-15-kline-research-studio-design.md

用户已授权重做交互，当前会话在指定目录内直接执行；不另建工作目录或要求重复批准。

- [x] 数据状态：为预测单独提供 loading/ready/error 状态，加载规则与行情并行，搜索避免污染行情状态。用 provider 回归测试验证失败与快速切换。
- [x] 研究依据：新增 research-context.ts 与测试，验证近期指标、候选历史窗口不重叠、不使用观察窗口内未来数据、不足时返回空。
- [x] 工作台：新增 research-studio、stock-picker、forecast-panel、research-evidence 及独立 CSS。接入根路由和 /chart；使用现有画布、绘图存储和接口。
- [x] 图表：新增 studio 呈现，简化工具条、直接展示水平线、窗口切换后保留完整历史计算的指标，侧栏与绘图属性按需切换。
- [x] 验收：执行 npm test、npm run lint、npm run build 和 Playwright 核心流程，使用内置浏览器检查实际页面与移动端；记录服务限制和验证结果。

每个功能修改先用能验证用户行为的测试证明缺口；纯样式改动用浏览器检查。完成后保留本地可评审修改，不自行部署。

## 验证记录 · 2026-09-15

- `npm test`：45 个文件、277 项测试通过。最终模型参考值文案调整后，相关 7 项预测明细测试再次通过。
- `npm run lint`：通过。`npm run build`：生产编译、TypeScript 和 22 个静态页面生成通过。
- `PLAYWRIGHT_CHANNEL=msedge npm run test:e2e`：30 项通过，6 项按桌面/手机设备排除不适用场景。手机摘要与触控高度调整后，新工作台的 3 项手机流程再次通过。
- 独立代码审查发现并修复：旧锚点因显示窗口切换而消失、对象列表无法定位早期对象、拖拽完成后的 click 清除选择、20 根数据时误报前 20 日量比；都有对应回归测试。
- 真实 A 股查询与行情接口接入保持现有后端；本地后端返回 502，未声称完成真实行情服务联调。成功数据流通过受控 API 响应验证，失败路径用实际未连接状态检查。
- 示例数据使用 DEMO；带账户令牌时也不会发起同步读取、加入同步队列或重放上传，专门测试已通过。

## 视觉复核

使用内置浏览器验证逐日预测与 BOLL 联动；内置浏览器长截图出现重复拼接，交付 PNG 改用项目已安装的 Playwright 和本机 Edge 截图。没有添加浏览器依赖。截图尺寸为桌面 1440×1000 和手机 390×844，最终 PNG 已逐张打开检查。

| 检查点 | 发现与处理 |
|---|---|
| 页面结构 | 首页直达画布；桌面选股/绘图/预测分栏，手机选股和明细使用抽屉 |
| 文字与字号 | 修正手机股票名称竖排；摘要改成两列两行，标题和价格完整可读 |
| 图标 | 移除旧样式产生的重复字符图标，绘图工具统一使用 SVG |
| 实际/未来区分 | 未来区占可见画布 15%，底色、分界、蜡烛与 MA/BOLL 延伸虚线共同区分 |
| 日期和视图 | 增加交易日期轴，30/60/120/全部保留完整指标和绘图坐标 |
| 手机触控 | 关键工具至少 44px，底部绘图栏和预测抽屉可用，无页面横向溢出 |
| 数据表述 | 示例、原始行情、基准推演及未校准模型参考值明确区分，规则出处与阈值可展开 |

图片生成工具不可用，未生成或声称存在已获用户认可的位图概念；以代码原生界面与上述实际浏览器检查作为交付依据。
