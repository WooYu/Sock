# 常见行情周期与完整MA组

用户要求：MA包含5、10、20、30、60、90、120、250；图表提供年、季、月、周、日、分时及常见分钟周期。

实施口径：
- 日/周/月/季/年及1/5/15/30/60/120分钟K线；60分钟显示为1小时，120分钟显示为2小时。分时独立显示价格线与成交均价，不能用1分钟收盘序列伪造分钟OHLC。
- MA(N)始终表示当前周期的N根完整或正在形成的K线收盘均值；不足N根返回空，不能用短均值冒充MA250。BOLL20/2同样需要完整窗口。
- 周/月读取原生周期历史，季度和年度由月K聚合，避免用短日线窗口得到不足的高周期历史。分钟线读取真实分钟OHLC，午间休市不能当成交易分钟；2小时以早盘/午盘分别聚合。
- 数据包含来源、复权口径、获取时间、历史范围；默认不复权。当前未完成K线随行情更新。长周期MA需要对应根数，250年或250季等数据不足是正常可见状态。
- 行情接口未配置时使用已验证的腾讯公开延时数据；配置的原后端保留其入口。来源失败应明确显示，不能把日K改名为分钟K。
- 八条MA独立开关并按周期保存；预测日线追加的MA以历史收盘和预测收盘计算。3日预测仍是3个交易日，不因切换分钟线改成3根分钟K。
- 时间/价格绘图按新周期隔离保存，支持分钟时间戳，兼容既有日/周/月工作区。

预测建议：先保持可解释的基线、相似走势和经验参考位；下一阶段用多股票、按时间留出的分位数树模型（如LightGBM/CatBoost）验证收益率分布与高低区间。Agent负责知识提取与证据，数值模型负责预测；不因单股回测或均线误差小就宣称有效。

验收：真实接口探针、周期聚合边界/午休、严格MA预热、分钟工作区持久化、异步切换竞态、分时VWAP、桌面手机图表流程，以及现有测试/构建。

## 实际验证

- 全套49个测试文件、387项测试通过；lint、TypeScript与生产构建通过。
- 端到端39项通过，7项为设备不适用的场景跳过；覆盖全部周期、八条MA开关、分钟绘图刷新恢复与周期隔离。
- 新易盛真实数据：日640、周540、月127、季43、年11根；1分钟638（含竞价归并）、5/15/30/60分钟各640根、120分钟320根、分时242点。来源显示“腾讯公开行情·延时”，分时说明不含盘后定价。
- 新增回归保证：扩展历史失败保留已有日线；刷新股票行情会刷新当前分钟图；旧周/月锚点按周期桶匹配；预测MA与BOLL基于同一历史和预测收盘，BOLL中轨与MA20一致。
- 桌面1440×1000与手机390×844实际截图已查看，无页面横向溢出或运行时异常。沿用内置浏览器不可鉴权时的本机Edge/Playwright验证方式。
- 默认不复权；公开接口返回可用历史，部分源请求最多640根。MA250按当前周期250根计算，月/季/年数据不足时留空。
- 预测服务仍是独立的日线三日接口。此轮没有把推荐中的新模型当作已部署模型，也没有把日线预测重命名成分钟或年月预测。
