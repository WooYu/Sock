# 经验、交易原则与提示的研究闭环

这份设计针对用户补充的十条经验及 GitHub 股票笔记，配套本次新易盛真实行情回溯检验。当前交互在 `/knowledge` 落地为本地工作台，研究结论和原文可见；新条目、解释确认和编辑追加本机版本，不声称已同步云端或自动启用交易。

## 三种知识的职责

| 类型 | 含义 | 例子 | 如何影响预测 |
|---|---|---|---|
| 经验 | 有适用情境的待检验关系 | 葛二调整、照镜子后两日、海龟 | 筛选相似案例、提出条件路径，保留反例 |
| 交易原则 | 可执行的资格、持有或退出约束 | 五日/十日线同时下降不新开多头 | 过滤行动和标记风险，不强迫数值价格满足主观愿望 |
| 临时提示 | 对特定股票、时段或计划的观察 | 观察10:30–13:50、某趋势线支撑 | 限定股票和有效期，过期后保留复盘记录 |

不得把“确认了AI解释”理解成“已经证明有效”；也不得把一条禁做原则当成一条做空价格预测。

## 管理实体与不可覆盖历史

1. `SourceRevision`：来源Git仓库/提交/路径，或用户手动原文；内容hash、录入时点、附件读取状态。原文和修改后的解释分开。
2. `KnowledgeItem`：稳定ID、经验/原则/提示类型、主题、所属股票/品种、时段/周期、有效期。
3. `KnowledgeRevision`：版本号、前一版本、AI解释、计算条件、待定义字段、例外/冲突、来源行号和逐字引文、编辑者、确认状态。修改解释或参数必须生成新版本。
4. `TestRun`：知识版本集合、行情版本、复权方式、时间拆分、代码版本、参数、基线、逐日预测账本与汇总。旧回测不能被新版本自动继承。
5. `ApplicationPolicy`：经单独批准的适用品种、模式、优先级和启用版本。确认解释、通过回测、启用必须是不同动作。
6. `PredictionSnapshot`：预测原点、行情截止时刻、近期走势特征、实际引用的知识版本、历史相似片段、预测路径、MA/BOLL和参考价位、冲突/缺失数据。发出后冻结。
7. `Feedback`：后续实际走势、偏差、参数触达、原则是否适用、人工纠错、标注发生时间。不能按后来涨跌改写原始预测或当时标签。

本地JSON/IndexedDB可保存草稿和版本，后续数据库沿用上述实体。云端需账户隔离、乐观并发版本检查和追加审计；不是直接把一段最新自然语言覆盖到“规则”表里。

## 页面和操作

- 经验库：按类型、来源、确认状态搜索；显示“待解释/待补定义/可研究”，避免用统一成功徽章暗示盈利能力。
- 来源资料：140份Markdown、固定提交、原文证据；图像/音频未读和转录歧义可见。
- 详情：原文 → AI解释 → 适用情境/条件 → 失效与例外 → 回测证据。保留“葛二退出”与“强势/封板可持有”等互斥情境，不能机械相互抵消。
- 手动录入：选择经验/原则/提示，填原文、可选解释、股票、提示到期日；原文单独保存。当前无需外部AI密钥的界面不把关键词规则声称为实时AI生成。
- 编辑：新增版本、可查看旧版本。确认解释只确认含义，不切换生产预测。
- 回测证据：真实数据范围、3/4日对比、对照模型、误差、方向基线、方法边界和缺失条件。
- 图表工作台链接到经验库；未来执行层应提供“本次用了哪些经验/哪些原则阻止行动”清单。先让依据可检验，再决定是否启用。

## 三天MA5与三天上轨

当前解释为未来三个交易日的MA5候选买入参考、BOLL上轨候选卖出参考，不是连续三日站稳才买。每个参考位需保存生成时点、指标计算版本和适用形态。

近期走势提供价格路径/振幅；经验提供候选参考位及情境；交易原则负责风险和资格。三层应独立可关闭、能做消融对比。

“当日可触及几个参数”本次用近20日真实波幅中位数、收盘上下各一个波幅的研究带，并按0.1%合并相近价位。该设定是显式研究假设，不是笔记原文的完整公式。分别评估参考位被次日高低范围覆盖、参考位相对高/低点的误差、以及可达数量偏差，绝不把同日覆盖买卖位当作已实现交易收益。

ETF是否T+0按具体品种确认；10:30–13:50是用户可转债观察窗口，并非交易所完整开市时段。新易盛A股日线无法验证转债、竞价、分时先后、热点板块、K线拆合或股感。

## 是否持续训练Agent

优先持续记录和评估，而不是无休止微调大模型：

1. 每个交易日追加行情及已到期预测的真实结果，自动检查数据质量和适用情境。
2. 固定版本定期做时间顺序复评，对照简单基线；检查市场状态变化、错误区间和冲突。
3. 对来源解释错误，先改术语词典、检索和结构化约束，并保留人工标注评测集；有稳定足量标注后才考虑针对解析任务微调。
4. 对数值预测误差，研究的是价格/条件分布模型，应多股票、多市况、时间留出校准；Agent负责组织证据和流程，不能靠“自我反思”改写结果证明有效。
5. 对风险原则和止损纪律，保持显式版本审批；即使模型建议修改，也不能依据最近几笔盈亏自动重写。

当前单只股票、约725个日线观测不支持“大模型越训越准”的结论。新模型必须在跨股留出和后续前瞻记录中证明增益，才有理由替换已有方法。
