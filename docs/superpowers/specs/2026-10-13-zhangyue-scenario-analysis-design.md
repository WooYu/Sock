# 掌阅科技：按走势、葛阶段与盈利模式组织分析

## 用户目标与范围

首个股票为掌阅科技（603533）。按用户指定顺序分析：真实日线与小时K线 → 趋势与葛阶段 → 盈利模式 → 前三后三参考参数 → 交易原则与止盈止损。重复、无关或不适用的旧规则可不参与本次分析，保留原文与忽略理由。

用户进一步明确短线重点：当前价格可能触及未来第1、2、3根K线所对应的MA/BOLL参考水平。因此参数表提前服务于当前交易窗口，而不只在各参数所属的未来日期才检查。日线和小时线都是首版核心输入。“通常能达到”作为待验证的触达假设，不预置命中概率。

用户补充大阳线后的观察顺序：由日线逐级下钻到1小时、30分钟K线。首版加入真实30分钟行情作为大阳线分支的确认层；仍无法确认时保留待确认，不强制继续下钻或给出动作。

已实现的笔记标签目录保持独立：标签说明笔记内容，不随掌阅科技当前涨跌改变。每次股票分析根据当时状态检索和选择知识版本，留下引用链。

推荐首版采用“固定计算 + 有证据的候选形态 + 人工确认”。完全人工判断不易复跑；完全自动识别需要先解决形态阈值和标注不足。首版直接计算客观指标，对缺少完整定义的形态返回候选或待确认，不把术语匹配当成识别成功。

## 1. 多周期行情与指标

- 复用现有 `getPublicChartSeries` / 图表接口，请求 `day` 与 `60m`。小时线来自实际分钟行情；日线无法生成真实小时线。
- 首版各周期使用相同的不复权价格口径。记录来源、采集时点、行情截止时点、复权方式及有效根数；除权等价格不连续事件需要另行标记，不能直接归为暴跌。
- MA5/10/20、BOLL20（总体标准差，2倍标准差）、量能和波幅均按所属周期计算。小时MA5指5根小时K线；日线原则里的“五日线”仍指日MA5。
- 只用分析时点已经结束的K线进行正式确认。盘中未完成K线单列为观察值；不能拿最终全天高低点回填早盘判断。
- 行情缺失、时间错位、非法OHLC或所需指标历史不足时，输出具体缺项。小时数据不足只停止依赖小时线的确认，不伪造小时走势。

- 大阳线分支使用现有 `30m` 行情接口继续下钻。日线负责趋势、位置和日线葛阶段；1小时负责观察大阳线后的延续、横盘消化或回撤；30分钟细化突破／回抽、量能和失效位置。各层记录同一分析时点及各自最新完整K线。
- 日／小时／30分钟状态可以不同；小周期的反弹不直接覆盖大周期的下跌背景。日MA5、小时MA5和30分钟MA5分别命名，风控使用选定模式明确引用的底线。
- 数据加载先获取日线与1小时，大阳线分支或用户主动下钻时再读取30分钟。30分钟缺失或滞后时保留上层分析，标记该确认层不可用。

## 3. 葛阶段采用有起点的事件序列

“葛几”不等于连续上涨天数，也不等于摸线三期。分别保存上涨、下跌语境、起点K线、计数周期、重置事件与确认状态。

- 上涨语境候选：从MA5附近起步、形成阳线并远离MA5；跳空等分支独立说明。触线容差、大阳线阈值等未确认时，需要在图上确认起点。
- 下跌语境候选：破五后下跌／反抽，不能沿用上涨计数的动作。
- 起点确认后，按对应周期的有效K线推进计数；遇到新的有效起步或复合形态，另存重置记录。
- 若用户确认的是日线葛阶段，不能把过去的几根小时线直接当作葛一、葛二、葛三的交易日。

## 5. 前三后三参数表

默认解释结合笔记与用户补充：用同一周期最近三个已知MA/BOLL参数外推后三根K线的参考位，并判断这些未来参考位能否在当前交易窗口提前被价格覆盖。日线使用日线参数，小时线使用小时参数。

基础可复算版本：对同一指标X，取已知 `X(t-2), X(t-1), X(t)`；计算 `d1=X(t-1)-X(t-2)`、`d2=X(t)-X(t-1)`、`d=(d1+d2)/2`；预测参考参数 `X_hat(t+h|t)=X(t)+h*d`，h为1、2、3。

每个价位同时记录所属周期、指标、生成时点、目标交易日／目标K线、计算版本和适用模式。日与小时的周期计数、休市时间分别处理。预测MA/BOLL水平作为参考位，不直接改名为未来收盘价或必然高点。

首版展示日线与小时线各自的未来第1、2、3根参数，指标包含MA5、MA10、MA20和BOLL上／中／下轨。每个价位另保存当前执行窗口与可达状态：当前可观察、需进一步确认、超出研究波幅范围或数据不足。任何基于历史波幅的可达带属于独立研究假设，参数必须明示；没有确认该口径时展示候选与距离，不输出已校准的触达概率。

参数所属K线与触达窗口是两个字段。例如，当前窗口可以覆盖“未来第2根小时K线的预测上轨”。记录一次窗口内覆盖了哪几个候选位，以及分别属于哪个周期和期限；相近价位合并时仍保留这些来源。

未来K线编号始终相对记录中的计算原点，不用“明天”等词隐含计算原点。在盘前只有昨日完整日线时，明确原点为昨日、第一根预测日线为今日；若用户选择的目标是从今日起算的明天／后天／大后天，则对应距昨日原点的第2／3／4根日线。界面显示实际目标日期或小时段，避免整体错移一根。小时线编号按真实交易时段推进，跳过午休、休市与节假日。没有已核实且覆盖目标区间的交易日历时，保留相对根数，目标日期标为未知并显示缺项，不用工作日推算冒充交易日历。

当前交易窗口开始前生成的计划冻结；盘中重算另存时点和版本。历史评估只使用窗口开始前已生成的价位，禁止用当日收盘后的参数解释当日早盘已经覆盖的价格。

原文中的“差值较大时用最新差”“增量递增时跟着递增”“根据葛几增减”作为独立待确认修正项。没有判定阈值或增减量时，首版不自动套用，也不编造修正系数。

### 单根大阳线后的计算分支

用户指出单日大阳线会使前三天平均增量失真。本分支采用价格情景滚动重算MA/BOLL；三点平均增量和笔记中的最近一天增量保留为对照方法，不声称本分支已有预测优势。

先记录大阳线相对位置、实体／上影、量能、均线乖离，以及后续小时线是否继续抬高高低点、横盘或回撤。人工确认冲击事件时记录确认时点；自动识别的实体／波幅阈值属于另行版本化的研究定义。

基准情景：后三根收盘保持在计算原点已知收盘价。延续与回撤情景：使用预先固定的同形态历史路径，或明确选定的突破位、原点均线、实体中部等条件价位；不得暗中添加任意涨跌百分比。没有样本支持时不输出情景概率。

每给定一条假设收盘路径，就逐根加入未来收盘、移出窗口最旧收盘，再计算各周期的MA5/10/20及BOLL20。对n周期均线，下一根为 `MA_n(t+1)=MA_n(t)+(C_hat(t+1)-C(t-n+1))/n`；后两根继续按更新后的窗口计算。BOLL从同一窗口的均值与标准差重算，以保持轨道结构。

示例仅用于验算：此前19根收盘均为10，当前大阳线收盘11；若后三根收盘保持11，未来MA5为10.40、10.60、10.80，BOLL上轨为10.70、约10.86、11.00。三点平均增量对应MA5为10.30、10.40、10.50。差异来自滚动窗口，而不是已验证的价格预测能力。

输出三种情景下的参考位及其条件，配合真实小时线选择当前更有依据的模式，保存重算版本。大阳线尚未收盘时，日线指标和该分支输出明确标为盘中暂估。只有大阳线收盘后才能使用收盘值作正式原点，不能将其结果回填到当日早盘计划。

大阳线后的观察顺序固定为日线→1小时→30分钟。按已结束K线更新各层证据：1小时观察消化／延续／回撤，30分钟进一步确认对应突破或回抽事件。首版也允许查看30分钟后三根MA/BOLL参考位，并保留其周期标签；它们不是后三天参数。向下钻周期时重新评估候选情景，不能据30分钟暂时反弹自动确认日线转强。

2026-10-15按用户补充要求更新跨周期合并口径：用两价平均数作为相对差分母，按1%阈值做完整链接分组，避免相邻链式合并扩大组内跨度；组内保留所有原始值与来源，代表值取所有唯一有效参考位的算术平均。综合结果只纳入当前选定的一种计算方法；滚动方法每个周期选择一条条件路径，未另选时使用基准路径。日线、1小时、30分钟缺失或未加载时明确显示未纳入；盘中暂估单列。新快照保存合并定义与方法、情景选择；已冻结的旧0.1%／中位数快照保留原值。此1%表示候选参考位的相近幅度，不表示已知的未来预测误差。

2026-10-15补充单日价位阶梯：以最近完整、不复权日K的收盘价为0%基准，按选定的单日涨跌幅和0.01元价格单位计算上下界；按用户更正，上下分别展示范围内全部实际合并位，按距收盘价由近到远排序，数量完全由计算结果决定。越界组不截断至涨跌停，保留在原始合并价位中。取消档数选择、截断与等分补位；空侧明确显示暂无有效计算价位。同一价格单位合并来源，等于收盘价的价位不重复列入上下两侧。每个百分比按最终显示价相对基准计算。此约束对应基准收盘后的一个交易日，其他周期未来根数仍各自计数，不把多日涨跌幅复合到此单日区间。

板块代码识别只提供普通主板10%、创业板／科创板20%、北交所30%的常规假设，明确提示尚未核实风险警示、上市初期及除权参考价；ST、退市、N／C状态或未知代码不自动设限，允许手动选择5／10／20／30%或标记不限幅／待核实。若已核实交易日历或同股票15:00完整小时／30分钟K线证明存在更新的已完成交易日，暂停使用过期日线生成区间，提示刷新。低价导致单侧区间取整后与收盘价重合时，须核实最小变动规则，暂不声称得到有效涨跌停区间。新快照用可选的`dailyPriceLadder`、`daily-close-levels-v2`口径冻结规则来源、完整日K基准、区间、全部实际价位、涨跌百分比及越界组ID，不保存固定档数；载入时重新计算并验证一致。旧`daily-close-ladder-v1`快照按原值保留并标明历史口径，新分析不会生成旧口径。

一致性检查：价格有限且大于零；BOLL下轨≤中轨≤上轨。独立外推违反轨道次序时标记无效，不通过交换轨道掩盖失败。

## 6. 交易原则与止盈止损

原则按选定模式、周期、持仓状态应用，不用所有规则的固定优先级混投票。

- 攀升／趋势持有：显示选定MA5或其他已确认底线、上轨／目标参考位，以及触发退出的价格或形态条件。
- 照镜子／下跌反抽：显示预先选定的回抽压力、不能重新站回时的失败条件与转强分支；不自动套用上涨攀升的持有逻辑。
- 震荡：只有箱体边界定义后才显示对应区间参考位；箱体失效单列。
- 风险原则可否决新增参与；即使仍展示研究参考参数，也明确其尚不满足参与条件。
- 原文给出的是动态底线或时间退出条件时，输出动态条件或截止周期，不能强行转成固定价格。
- 没有成本、持仓数量和账户信息时，仅输出技术参考位及失效条件；不声称实际盈利金额、收益率或适用仓位已经计算完成。

## 7. 重复与不适用规则的处理

每条候选记录本次状态：已采用、不适用、条件不足、重复引用、人工停用。保留理由、原文和版本。

- 相同条件、模式、周期、动作与例外的规则合并展示，保留全部来源。

## 8. 页面与数据契约

在现有K线研究工作台增加分阶段分析视图：数据时点 → 日／小时状态（大阳线可继续下钻30分钟） → 葛事件起点 → 模式候选 → 前三后三参数表 → 原则与止盈止损参考 → 本次采用／忽略的笔记。

分析快照独立于静态标签，至少保存：股票、行情快照与完整K线范围、各周期状态与确认来源、葛事件、模式版本、原始与合并价位、原则结果、知识版本、忽略理由、生成时点。修订追加版本，不能覆盖历史。

复用现有行情接口、指标计算和标签来源目录；新增分析结果以独立类型承载，再适配现有面板。旧 `granvilleDay`、`phase`、`mirrorRetest` 目前是空事实，接入有定义的状态后才能用于规则判断。

## 9. 验证与首版验收
