# 建议的预测方案

推荐主线为“分位数收益率模型 + 历史相似案例对照 + 显式经验/原则约束”。Agent负责知识解释、检索和证据，不直接承担数值价格预测。

## 当前证据与选择

新易盛最近一年时间留出检验：未来3日MAPE，价格不变5.80%，原有趋势6.20%，历史类比5.89%，类比加经验状态5.90%。经验组合的改善区间跨0，尚不能证明已获得价格预测优势。该结果只能支持保留对照、扩充验证，不能支持不停微调Agent或切换成更复杂模型就会更准。

## 建议的数值模型

- 第一候选：LightGBM分位数回归。目标为未来1/2/3/4交易日收益率的P10/P50/P90，而不是跨股票直接学习绝对价格。CatBoost可作为类别特征更多时的对照。
- 先保留价格不变、20日趋势、历史类比三个基线，单独检验新模型增益。不要先堆深度时序网络或在线自动自训练。
- 特征包括：最近收益率路径、振幅/ATR、成交量变化、MA5/10/20/30/60/90/120/250位置与斜率、BOLL位置/带宽、完整高周期趋势及当时已知的低周期结构。避免为了“多周期”把未来周五/月底的最终数据带进周中预测。
- 市场和板块强弱、停复牌、涨跌停制度等只有在有对应时点的真实资料时纳入。缺失条件须保留为缺失，不能假定满足海龟/热点等情境。
- 高低价范围可用条件分布或历史轨迹估计，输出时强制OHLC及分位数顺序一致；价格路径不确定性不应被画成确定会发生的实体K线。

## MA与BOLL的预测

主图先得到未来价格路径，再把历史与预测收盘拼接，按各窗口重新计算MA和BOLL。这样同一条价格路径会产生一致的MA/BOLL，不会发生单独外推三条BOLL导致上下轨交叉。

“未来三天MA5买入参考／BOLL上轨卖出参考”作为经验层参考，独立记录适用形态和触达概率。近期振幅用于衡量哪些参考位可能可达；触达并不等于实际成交或盈利。笔记增量外推仍可作为研究对照，但应标记数学一致性失败和情境缺失。

## 原则层和解释

- 近期走势：给价格分布、振幅和相似案例。
- 经验：给形态、参考位、例外和条件分支。
- 交易原则：给行动资格、底线与失效条件。例如禁开多头不应被编码成强迫价格下跌。
- 每个预测快照记录原点、源数据版本、有效知识版本、使用的参考位、缺失条件及冲突。修改解释必须使旧测试失效。

## 训练与验证节奏

先做预先选定的多股票、多市场状态、滚动时间留出和参数冻结；未来4日目标的训练/验证边界至少剔除跨界4日标签。再保留一段真正未见过的前瞻纸面预测记录。

数值模型可以按固定窗口滚动重估或在数据漂移时重训，但每次都必须与旧版及简单基线比较，并允许回退。知识库可持续追加，Agent的提示词、检索和术语定义可改进；大模型微调仅在积累足量稳定的人工纠错/标注后考虑，不按几次预测成败反复训练。

这份方案是下一阶段的验证建议，本次周期扩展没有把未经验证的LightGBM/CatBoost宣称为已上线或已提高准确率。
