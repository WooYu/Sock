# K 线、绘图与未来推演重设计

日期：2026-09-07  
状态：已确认，待实施  
范围：Web 桌面端与手机浏览器；移除现有过时 Flutter 工程

## 1. 目标

把当前基于 SVG 屏幕像素坐标的 K 线标注升级为基于“交易周期 + 时间 + 价格”的图表编辑器，解决缩放、周期切换和响应式布局下标注漂移的问题。同时加入默认开启的未来 3 个交易日推演区，展示预测区间 K 线以及连续延伸的 MA 和 BOLL，并提供可直接查看的预测明细。

## 2. 已确认的产品决策

- 本轮先完成 Web，不同时维护现有 Flutter 客户端。
- 现有 Flutter 工程版本落后，直接从仓库移除；未来如需原生客户端，基于稳定的数据协议重新建设。
- 未来推演默认开启，固定展示未来 3 个真实交易日。
- 预测只展示一套基准方案。
- 后端先生成未来 3 日预测 OHLC，MA 与 BOLL 再基于“历史 + 预测”连续计算。
- 预测数据只读，用户绘图可跨入未来区域。
- 桌面端在 K 线下方使用可折叠明细表；手机端使用底部抽屉。
- A 股颜色遵循红涨绿跌。

## 3. 页面布局

### 3.1 桌面端

- 顶部：股票信息、周期、MA、BOLL、未来推演、撤销、重做和保存状态。
- 左侧：选择、平移、十字光标、趋势线、水平线、矩形、文字、买入、卖出、目标和止损。
- 中央：K 线主画布与成交量。
- 右侧：图层与属性检查器。
- 下方：可折叠“未来 3 日预测明细”。

### 3.2 手机端

- 顶部保留行情摘要和可横向滚动的图表控制条。
- K 线保持主视觉区域，不压缩为小卡片。
- 底部固定五个高频入口：选择、趋势线、水平线、标记、更多。
- 预测明细和属性编辑使用可拖动底部抽屉；预测日期使用明日、第 2 日、第 3 日分段切换。
- 所有主要触控目标不小于 44px，并适配安全区域。

## 4. 未来推演

真实行情与预测区以虚线分界和浅色背景明确区分。预测蜡烛使用半透明实体与虚线轮廓，MA5、MA10、MA20 和 BOLL 上、中、下轨从历史区连续延伸。

十字光标进入预测区时展示：

- 交易日期
- 预测开盘、最高、最低、收盘
- 预测价格区间
- MA5、MA10、MA20
- BOLL 上轨、中轨、下轨
- 置信度
- 预测生成时间与模型版本
- “推演数据，不是实际行情”提示

明细表与图表双向联动：点击某日明细时定位并高亮对应预测蜡烛；悬停预测蜡烛时同步高亮明细。

预测失败只隐藏预测层；真实行情和绘图继续工作。数据不足或规则冲突时显示“数据不足/不可判断”，不得伪造预测结果。未来日期必须按交易日历计算，排除周末与休市日。

## 5. 绘图编辑器

支持选择、平移、十字光标、趋势线、水平线、矩形、文字备注，以及买入、卖出、目标和止损快捷标记。

- 快捷标记自动读取当前位置价格并显示价格。
- 点击对象进入选中态并显示控制点。
- 支持整体拖动、锚点调整、复制、删除、锁定、显隐和层级调整。
- 属性支持颜色、线宽、线型、透明度、文字、价格和备注。
- 支持 Delete、Esc、Ctrl/Cmd+Z、Ctrl/Cmd+Y。
- 价格吸附可对齐 K 线开高低收、MA 和 BOLL。
- 水平线在右侧价格轴显示同色价格标签。
- 日、周、月绘图独立保存，不自动混用；可显式复制到其他周期。

## 6. 数据模型

绘图对象至少包含：

```json
{
  "id": "drawing-id",
  "symbol": "000001",
  "period": "1d",
  "type": "horizontal-line",
  "points": [{"time": "2026-09-07", "price": 3320.0}],
  "style": {
    "color": "#ef4444",
    "width": 2,
    "lineStyle": "dashed",
    "opacity": 1
  },
  "text": {
    "content": "关键压力位",
    "showPrice": true
  },
  "locked": false,
  "visible": true,
  "version": 1,
  "updatedAt": "2026-09-07T00:00:00Z"
}
```

预测快照至少包含 symbol、period、三个交易日的 OHLC、预测区间、MA、BOLL、置信度、生成时间和模型版本。预测快照不可被用户绘图修改。

## 7. 保存与同步

- 绘制和拖动期间只更新前端状态，操作结束后持久化。
- 本地立即保存，后端短延迟同步。
- UI 明确显示已保存、同步中、待同步和离线。
- 后端不可用时写入离线队列，恢复后按顺序重放。
- 使用对象版本和更新时间处理并发修改。
- 冲突默认保留新版本，同时保留旧版本恢复记录。
- 删除与异地修改冲突进入待恢复状态，不静默丢失。
- 导入和导出使用稳定 JSON 协议，不绑定具体 UI 框架。

## 8. 前端模块边界

- `ChartViewport`：行情渲染、缩放、平移、十字光标及坐标转换。
- `IndicatorLayer`：历史与预测 MA/BOLL。
- `PredictionLayer`：未来背景、分界、蜡烛和置信度。
- `DrawingEngine`：创建、命中检测、拖动、控制点、吸附、撤销和重做。
- `DrawingToolbar`：桌面和手机工具入口。
- `ObjectInspector`：对象属性编辑。
- `LayerPanel`：图层管理。
- `PredictionDetails`：桌面表格和手机抽屉。
- `DrawingRepository`：本地保存、后端同步、离线队列和冲突处理。

## 9. 错误处理

- 行情失败：保留已有绘图，提供重试。
- 预测失败：只关闭预测层。
- 保存失败：保留本地修改并显示待同步。
- 指标参数无效：阻止应用并显示明确错误。
- 预测记录过期：显示生成时间，不冒充最新结果。
- 坐标找不到对应交易日：保持对象数据，提示该对象暂不在当前可视范围。

## 10. 测试与验收

- 时间/价格与屏幕坐标双向转换单元测试。
- MA、BOLL、未来交易日和预测数据映射测试。
- 吸附、命中检测、控制点与对象移动测试。
- 创建、编辑、删除、复制、撤销和重做交互测试。
- 日/周/月周期隔离、刷新恢复、离线同步和冲突测试。
- 预测蜡烛与明细双向联动测试。
- 桌面和手机响应式、键盘、触控与可访问性测试。
- 使用真实 Chrome 进行核心流程验证和概念图截图对照。
- 重点验收：缩放、平移、窗口变化和刷新后，绘图对象不漂移。

## 11. 非目标

- 自动交易和券商下单。
- 同时展示乐观、基准、悲观多套情景。
- 延续或修复当前 Flutter 客户端。
- 在预测数据不足时由前端伪造走势。
