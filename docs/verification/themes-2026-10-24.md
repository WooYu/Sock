# C / D 主题验收与发布

## 使用方式

在「设置 → 外观主题」切换，也可从研究工作台右上角的「外观」进入。

- C 清爽自然：等线、灰绿底色、森林绿强调，默认启用。
- D 深色科技：微软雅黑、深蓝底色、青色强调，行情数字使用 Bahnschrift 等宽数字。
- 字体优先使用设备已有字体；缺少字体时使用系统中文字体回退。偏好保存在当前浏览器，刷新及页面跳转后恢复；禁止本地存储时仍可在当前页面切换。

语义颜色覆盖工作台、图表、知识、规则、交易、设置以及弹窗。涨红跌绿和 MA/BOLL 指标各自的识别色保留。

## 验证范围

使用本地生产构建、Edge Chromium，桌面和 iPhone 13 尺寸分别检查 C / D；另检查 375px 窄屏、812px 横屏、键盘操作和减少动态效果设置。21 个路由入口包含历史入口的重定向行为。

功能检查覆盖搜索与自选、行情周期与复权、绘图编辑及撤销恢复、分时、MA/BOLL、预测详情、知识筛选与编辑、笔记研究、快照与导出、规则草稿和发布校验、交易与持仓恢复、登录弹窗及主题持久化。

浏览器用例隔离共享同步和未显式模拟的写请求，避免测试记录进入真实共享账户。`@real` PostgreSQL 集成用例需要专门的隔离服务，本次前端验收未启用。行情、预测计算与原始研究资料的定义没有修改。

## 修复与测试维护

- 存储被禁用时，账户状态读取不再使设置页面崩溃。
- 知识工作区切换写入浏览历史，浏览器后退可恢复原视图。
- 手机图表将指标设置和视图操作分行，避免指标菜单遮挡撤销按钮。
- 旧浏览器用例更新为当前导航、手机按钮名称、Ctrl＋滚轮缩放和逐级分析行为；模拟行情的最小价格单位及截至时间与冻结样本对齐。
- Windows 工作区为带哈希绑定的研究资料显式保留 LF，未修改笔记或冻结结论。
- 本地完整浏览器运行后按失败项和未完成项分组复测，统计按主题、设备、文件和用例名称去重；跟踪记录收尾卡顿的组关闭跟踪后重跑。
